# Simulador Bancário em Python

Este é um simples simulador bancário desenvolvido em Python para praticar estruturas de controle, condicionais e manipulação de variáveis. Ele permite visualizar saldos, fazer depósitos e realizar saques na conta corrente.

## 💻 Funcionalidades

- Ver saldo da conta corrente
- Ver limite do cartão de crédito
- Ver saldo da poupança
- Fazer depósitos na conta corrente
- Realizar saques da conta corrente
- Encerrar o programa com segurança

## 🧾 Como usar

1. Certifique-se de ter o Python instalado em sua máquina.
2. Clone o repositório ou copie o código para um arquivo `.py`, por exemplo:

```bash
git clone https://github.com/seuusuario/nome-do-repositorio.git
cd nome-do-repositorio
python simulador_bancario.py
Ao iniciar o programa, você verá o menu com opções numeradas. Basta digitar o número correspondente à ação desejada.
